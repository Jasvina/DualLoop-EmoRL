# Runnable Experiment Releases

`work_sagevar_passctrl_train500_n4` is a separate profile-level curriculum
experiment. It includes its runtime, generated 500-profile training pool,
profile-generation utility, and launcher. It is not the 24-state hierarchical
method reported in the paper.

The matching transfer archive is stored under `artifacts/`. Files from the
superseded three-difficulty/1,500-profile design and local backup files are
intentionally excluded from this release.
